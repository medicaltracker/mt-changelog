## Released 10 November 2026
### :left_right_arrow: Trust overview: Choose between tile or table view
* Default is the TILE view; any change is remembered for the session.
* The table can be sorted to make it easier to identify schools that might need support, for example, schools that haven’t logged an incident in some time, or aren’t using the **Medication use** module.
* Data can now be exported to CSV from both views via the Export button

### :sparkles: Trust overview: Small visual changes
* Improved alignment of items in the top right along with a link to this **Updates** file
* Please note that **Sign out** is now ONLY available in the lower left corner

### :bug: Bugfixes
* Incident types without a 'what happened next field' (e.g. near misses) are no longer included in the **What happened next report**
* Header and footer images now display for UAE schools

## Released 3 November 2026
### :clipboard: New care plan fields
* We've updated our care plan fields to align with the language and order of the fields in the DFE's allergy and asthma template. All fields are optional and appear on page 2 of the form, after you click Next.
* We recognise the importance of capturing this information for students with any condition, not just allergies, and so have made these available in all care plan types.
* Learn more about this change in our [knowledgebase article](https://help.medicaltracker.co.uk/en/ihp-updates-2026).

## Released 15 October 2026

### :lock: Strengthened permissions around adding incidents

* We've recently strengthened permissions around adding incidents.
* To ensure that staff can add incidents to the platform, they must belong to a team with the following permissions ON:
    * Incidents module
    * Students add
    * [where appropriate] Staff add
* Learn more about how to change team permissions in our [knowledge base article](https://help.medicaltracker.co.uk/en/add-incident-permissions).

## Released 1 October 2026  

### :sneezing_face: New automated allergy email notification

- Staff can now choose to receive an automated notification when an allergy has been recorded. This is particularly useful for keeping school allergy champions in the loop.
- The notification is triggered when an illness is recorded, and allergy is selected from the dropdown menu, as in the example below.
- Learn how to control the notifications staff members receive in our [knowledge base article](https://help.medicaltracker.co.uk/en/how-to-set-staff-notifications1).
